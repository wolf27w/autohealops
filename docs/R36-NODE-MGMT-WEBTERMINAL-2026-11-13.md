|---|---|

| 分组 | 可展开/折叠；显示主机在线状态点（绿/红/灰） |
| 未选主机 | 右侧显示引导：「从左侧选择节点开始会话」+ 快捷键说明 |
| Tab 超出宽度 | 横向滚动，不换行挤压 |

**保留现状**：多标签 xterm、空闲 10 分钟断开、会话录制、强制下线、SFTP（T3 后改为右侧侧栏）。

## 五、T1 命令审计 + 危险命令拦截（最高优先级）

### 行为
1. 用户在终端里敲命令（回车确认一行）→ 后端 WebSocket 侧先做**黑名单匹配**
2. 命中 → **不执行**，向前端发 `blocked` 帧：终端打印红字 + 前端弹窗（标题「危险命令已被拦截」，内容含：命令原文、命中的规则名、建议）
3. 未命中 → 正常下发执行，同时把该命令**写入审计表**
4. 审计只记录「用户主动输入的行」，不记录程序输出；多行粘贴按行拆分逐条判定

### 危险命令库（初始，可配置）
`rm -rf /` · `rm -rf /*` · `mkfs.*` · `dd of=/dev/` · `shutdown` · `reboot` · `halt` · `poweroff` · `init 0` · `chmod -R 777 /` · `chown -R /*` · `> /dev/sda` · `:(){ :|:& };:`（fork 炸弹）· `kill -9 1` · `mv /* /dev/null`
> 规则存表/配置，支持管理员增删改（后续可做页面；先内置常量 + 环境变量覆盖）

### 审计表（新增）
`host_command_audits`：`id, host_id, host_name, user_id, username, session_id, command, blocked(0/1), rule(命中规则), client_ip, created_at`
> 索引建议：`(host_id, created_at)`、`(user_id, created_at)`、（可选）`command` 前缀索引

### 与现有录制的关系
录制是**会话级**（tty 全量），审计是**命令级**（可检索）。两者并存，不互相替代。

## 六、T2 水印 + 禁止复制

### 水印
- 终端区域覆盖一层 CSS 水印：`用户名 · IP · yyyy-MM-dd HH:mm`（可加平台名）
- `pointer-events: none`，不挡操作；定时轻微位移+低透明度，防裁剪
- 仅覆盖终端渲染区，不影响功能

### 禁止复制
- 拦截 `copy` / `cut` 事件并清空剪贴板；右键菜单禁用
- 选中文本时允许框选（否则没法看），但复制不生效

### 粘贴（2026-11-13 17:19 老板定：做成开关）
- 平台设置里加「Web 终端」安全分区，4 个开关（默认值见下）：
  | 开关 | 默认 |
  |---|---|
  | 危险命令拦截 | **开** |
  | 允许粘贴 | **开**（关掉则终端内粘贴被禁用） |
  | 显示水印 | **开** |

- 开关落到现有 `settings` 机制（`PlatformSettings` 页新增「Web 终端」分区），改动即时生效（终端建立 WebSocket 时下发配置）

## 九、验收标准

1. 菜单显示「节点管理」，集群内显示「K8s 节点」；两处不混淆
2. 节点管理页右上「Web 终端」按钮，admin 可见；被授权 operator 可见；viewer 不可见
3. 终端里输入 `rm -rf /` → **不执行** + 弹窗提示命中规则 + 终端打印红字
4. 终端里输入 `ls -l` → 正常执行；`host_command_audits` 里有该条记录（含用户/主机/会话/IP）
5. 终端区域可见水印（用户名+时间），且水印不遮挡点击
6. 选中文本按 Ctrl+C → 剪贴板为空（复制被禁止）
7. 未授权用户直链打开终端 → 后端 4003，前端提示「无该主机操作权限」
