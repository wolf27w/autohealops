# AutoHealOps 后台整体布局 · 设计提示词

> 用途：交给设计/AI 出线框或直接生成页面时用的提示词。2026-11-11 整理。
> 现状基线：6 大模块 22 个菜单项，`MainLayout.tsx` 为「顶部栏 + 左侧菜单 + 内容区」。

## 一、完整版（推荐直接复制）

```
你是资深 B 端产品设计师。请为「AutoHealOps 自愈运维平台」的 Web 后台设计整体布局（交付：线框 + 组件说明，不要视觉稿）。

【产品定位】
面向运维/SRE 的 Kubernetes 自愈平台：接多个集群 → 采集指标与日志 → 产生告警 → AI 诊断 → 自动修复（重启/伸缩/回滚）或转工单 → 形成闭环。
核心使用场景是「值班处理」：用户登录后 3 秒内要判断"现在有没有事、我该先干什么"。

【整体骨架】
1) 顶部栏（固定，高 56px）：
   - 左：产品 Logo + 名称「AutoHealOps」（点击回首页）
   - 中：全局上下文切换器 —— 环境（qa/uat/prod）与集群（全部/单集群），带多选；切换后整个平台的数据范围随之变化，并在标题处显示当前范围
   - 右：全局搜索（集群/服务/Pod/告警编号）、告警铃（角标=未处理数，点开右侧抽屉显示前 10 条）、帮助、主题切换、用户菜单（含角色）
2) 左侧主菜单（宽 220px，可折叠到 64px 图标态，折叠状态记忆）：
   - 6 个模块，两级为限：监控中心 / 告警与工单 / 智能诊断 / 自动化运维 / 知识配置 / 系统管理
   - 每个模块下 3~5 项，禁止出现第三级（需要第三层时改为「页面内左侧二级导航」或「页内 Tab」）
   - 当前项高亮；分组之间留分隔标题
   - 按角色过滤：管理员全见，运维/只读隐藏「策略配置/通知配置/用户与权限/日志源/AI 配置/系统设置」等
3) 内容区：
   - 顶部：面包屑（可点返回）+ 页面标题（H1，20px）+ 右侧主操作按钮（主按钮最多 1 个）
   - 其下：筛选条（集群/命名空间/时间范围/关键词/状态）+ 表格或卡片
   - 列表行操作一律收进行尾「⋯」下拉；危险项（删除/下线）放分割线下方并标红，且必须二次确认弹窗
   - 详情一律**整页跳转**（可直链、可刷新），不用右侧抽屉；抽屉只用于"快速预览/通知"
4) 进集群后的特殊约定：从「集群管理」点进某个集群后，左侧菜单**整体切换为集群内导航**（顶部有「← 返回平台」），
   集群内导航只两级：概览 / 节点 / 应用负载（工作负载·服务·容器组）/ 存储 / 配置 / 监控告警 / 巡检与诊断；
   工作负载的类型（部署/有状态副本集/守护进程集/定时任务）用左栏底部下拉切换，不占导航层级。

【页面模板】（请给出这 5 个关键页面的线框）
A. 登录后首页（运行态势）：顶栏健康分 + KPI 5 项 + 告警趋势图 + 「需要我处理的」待办队列（按 P0~P3 排序，可点击下钻）+ 集群水位/数据库健康
B. 集群详情（应用负载 · 部署列表）：左上导航 + 命名空间多选 + 搜索 + 表格（名称/状态/副本/镜像/更新时间/⋯）
C. 工作负载详情整页：面包屑 + 名称与状态 + 右上「编辑设置/更多」+ 页签「概览/资源状态/元数据/环境变量/事件/监控」
D. 告警处理：左侧告警列表（可分组/按环境聚合）+ 右侧详情面板（AI 诊断结论 + 一键转工单/转诊断助手）
E. 系统设置：左侧二级菜单（常规/可观测性/AI/通知/保留期/安全）+ 右侧表单，改动即时生效提示

【视觉规范】
- 浅色为主、深色可选；主色 #1f6feb，成功 #1f9d4d，警告 #b25f00，危险 #c62828
- 卡片：白底、1px #e6e9ef 边框、圆角 8px、内边距 16px；表格紧凑（行高 40px），表头 #fbfcfe
- 字体：系统字体栈；正文 13~14px，标题 20px，数字强调用 600/700 字重
- 状态一律用「文字 + 颜色标签」，不只用颜色区分（色盲友好）

【交互与性能】
- 所有列表页支持：筛选、分页或虚拟滚动、刷新、导出（有权限时）
- 危险操作二次确认；批量操作需先勾选并显示影响条数
- 路由级懒加载；首屏可交互 ≤ 2s；轮询间隔 ≥5s 且页面隐藏时暂停

【交付要求】
- 每个页面标注区域划分（顶栏/侧栏/内容/抽屉）与组件选型（antd 组件名）
- 说明 3 个关键取舍：为什么用整页详情而不是抽屉、为什么菜单限制两级、为什么首页以待办队列为主
```

## 二、短版（一句话给 AI 出草图）

```
为 AutoHealOps（K8s 自愈运维平台）设计后台布局：顶部栏（产品名/环境+集群全局切换/全局搜索/告警铃/用户菜单）
+ 左侧两级菜单（监控中心·告警与工单·智能诊断·自动化运维·知识配置·系统管理）+ 内容区（面包屑+标题+筛选条+表格）。
规则：菜单最多两级；列表行操作收进 ⋯；详情整页跳转不用抽屉；进集群后左侧整块换成集群内导航（返回平台在顶部）；
首页以「需要我处理的」待办队列为核心。风格：浅色、主色 #1f6feb、卡片圆角 8、表格紧凑。
```

## 三、当前布局的问题（用于说服自己/对齐评审）

1. 没有全局「环境/集群」上下文切换 —— 用户在不同页面要重复选集群，且不知道自己当前在看哪个范围
2. 菜单有三级（故障诊断下三分类），与「最多两级」的目标冲突；建议改成「故障诊断」一项 + 页内 Tab
3. 详情多用右侧抽屉，导致无法直链、无法刷新保持、无法发给同事
4. 列表页筛选条与操作按钮位置不统一（有的在上、有的在左、有的在表内）
5. 首页卡片过多、无主次（11 张卡平铺）
