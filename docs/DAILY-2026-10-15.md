## 1. 智能诊断线（E1–E4）—— 应用诊断助手

| 功能 | 入口 | 自测步骤 |
|---|---|---|
| **JVM 结果全量接入诊断** | 应用诊断助手 → 新建会话（选一个 **Java 应用** 的 Pod）→ 提问 | 诊断结果的「工具调用」里应看到 **JVM 诊断**（vm_flags/heap_info/GC 直方图/线程栈）；结论会引用堆/GC 数据。非 Java 应用不出现 JVM 步骤（正常）。 |
| **诊断日志口径对齐** | 同上 | 工具「容器日志查询」结果含 **【上次实例(--previous)】** 段（重启/探针失败时尤其有用）。 |
| **主动诊断（应用巡检）** | 应用诊断助手左侧「**立即巡检**」按钮（admin） | 点击返回 `命中 N / 自动诊断 M`；命中的会话带橙色「**巡检**」标签、`source=proactive`。阈值/开关在 system_settings（`proactive_*`）。 |
| **故障类型模板** | 同上，提问带关键词 | 提问含「探针/liveness」→ 证据首段出现「**故障类型判定**」+ 探针配置段；含「CPU 高/HPA」→ 自动带 HPA/Deployment 证据。 |
