> 依据：2026-11-13 老板提供的 7 张 KubeSphere 3.4.1 截图（OCR 逐字提取）+ 官方文档 + 实地抓取的列表页 DOM。

## 一、创建 — 两步向导（截图实测）

### 第 1 步：基本信息
- 标题：`创建 ConfigMap` / `创建 Secret`；右上角按钮 **「编辑 YAML」**（一键切 YAML 模式）
- 步骤条：`基本信息`（当前）→ `数据设置`（未设置）
- 字段：
  - `名称*`（提示：只能包含小写字母、数字和连字符，必须以小写字母或数字开头结尾，最长 63 字符）
  - `别名`（提示：可中文、字母、数字、连字符，不得以连字符开头结尾，最长 63）
  - `项目*`（下拉；提示「选择将要创建资源的项目。」）
  - `描述`（提示：任意字符，最长 256）
- 底部：`取消` / `下一步`
- 校验文案：`请设置一个名称。` / `请选择一个项目。`

### 第 2 步：数据设置

**ConfigMap**
- `+ 添加数据`
- 两列：`键` / `值`
- 底部：`取消` / `上一步` / `创建`

**Secret**
- 字段 `类型`（下拉，当前值形如 `Opaque` / 显示为「默认」），提示 `选择一个保密字典类型。`
- 选项 4 个：`默认` / `TLS 信息` / `镜像服务信息` / `用户名和密码`
- 按类型渲染：
  - **默认**：`数据*` + `添加数据` + 提示「添加键值对数据。」
  - **TLS 信息**：`证书*` / `私钥*`
  - **镜像服务信息**：
    - `镜像服务地址*`（左侧带协议下拉 `https://`）
    - `用户名*`、`邮箱`、`密码*`（右侧「验证」按钮）
    - `设为默认镜像仓库` 开关 + 说明：「设置为默认镜像仓库后，如果没有特殊指定，系统将使用默认镜像仓库创建应用负载。一个项目中仅允许设置一个默认镜像仓库。」
    - 提示：「创建镜像服务保密字典前，请先验证用户名和密码。」
    - `数据*` + `添加数据`
  - **用户名和密码**：`用户名*` / `密码*`
- 底部：`取消` / `上一步` / `创建`

## 三、行操作（⋯）

KubeSphere：`编辑信息` / `编辑 YAML` / `编辑设置` / `删除`
我们的目标（多出的追加在后，删除置底）：
```
编辑信息 | 编辑 YAML | 编辑设置 | 查看信息 | 删除
```
- **编辑信息**：名称（只读）/ 别名 / 描述 → 走 `updateObjectMeta`（注解 kubesphere.io/alias-name / description）
- **编辑 YAML**：现有 `ConfigObjectYamlModal`（去掉「（高级）」后缀）
- **编辑设置**：只改数据
  - ConfigMap：`数据` 键值对 + `添加数据` + 取消/确定
  - Secret：`类型`**只读展示** + `数据*` + `添加数据` + 取消/确定
- **查看信息**：保留现有 `ConfigObjectInfoModal`
