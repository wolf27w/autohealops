## 二、页面级改造

### 2.1 通用（所有列表页）
- 统一 `PageHeader`：标题 + 一行关键指标 + 主操作
- 表格列：默认 5~7 列 + 「列设置」（其余列进详情）
- 操作：行内最多 1 个主操作 + ⋮（其余收进去）
- 状态：5 语义色（成功/警告/危险/信息/中性），去掉装饰性彩色
- 空态/加载/错误统一组件

### 2.2 具体页面
| 页面 | 现状 | 改造 |
|---|---|---|
| 集群列表 | 10 列 | 默认 5 列（集群/环境/状态/版本/自愈），其余进列设置；自愈开关保留 |
| 集群详情 | 工作负载类型 Tabs + 内部 Tabs | 类型改下拉；namespace 下拉保留；表格精简 |
| 诊断中心 | 多层 Tabs | 下拉切「集群/应用/数据库故障」；Tabs 取消 |
| 系统设置 | 9 个横向 Tab | 下拉切分区；一行一个分区 |
| 告警处理 | 列表 + 屏蔽/值班分散 | 下拉「列表 / 屏蔽规则 / 值班排班」 |
| 用户与权限 | 用户/项目/审批流/IM 群分散 | 下拉分组 |
| 任务中心 | 定时任务/执行记录分散 | 下拉「定时任务 / 执行记录」 |
| 知识库 | 日志源独立入口 | 下拉「知识库 / 日志源」 |

## 四、验收（不丢功能）
1. 对照第一节表格，**每个旧路由都能从新位置点到**；
2. 全局搜索能搜到所有页面；
3. 所有下拉项都渲染出原页面，不改页面功能；
4. 表格被隐藏的列都能在「列设置」里打开。
