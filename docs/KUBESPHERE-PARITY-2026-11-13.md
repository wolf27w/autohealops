## 三、创建/编辑弹窗实测（已抓到原文的部分）

### 配置字典
- 创建（两步）：**基本信息**（名称* / 别名 / 项目* / 描述，右上角「编辑 YAML」）→ **数据设置** → 创建
- 编辑分两个入口：
  - **编辑信息** = 名称 / 别名 / 描述（元数据）
  - **编辑设置** = 只有「数据」区：key + value 文本域 + 「添加数据」 + 取消/确定

### 保密字典
- 编辑设置 = **类型（只读展示）** + 「数据*」键值对 + 「添加数据」 + 取消/确定
- 创建时数据设置里可选类型：默认 / TLS 信息 / 镜像服务信息 / 用户名和密码（官方文档口径）

## 四、我们 vs KubeSphere（差异汇总）

| 维度 | KubeSphere | 我们 | 优先级 |
|---|---|---|---|
| 工作负载行操作 | 编辑信息 / 编辑 YAML / 重新创建 / 删除 | 编辑设置 / 编辑 YAML（高级）/ 伸缩副本 / 滚动重启 / 发布历史 / 删除 | 中（命名与分组对齐） |
| 工作负载创建 | 分步 + 每步独立校验 | 页签表单（已接近） | 低 |
| 容器组行操作 | 查看 YAML / 删除 | 监控/日志/进容器/JVM/编辑 YAML/隔离/删除 | 低（我们更全，保留） |
| 服务行操作 | 编辑服务 / 编辑外部访问 分开 | 一个「编辑设置」 | 中 |
| 路由行操作 | 编辑路由规则 / 编辑注解 分开 | 一个「编辑设置」 | 中 |
| 配置字典 | 两步创建 + 编辑信息/编辑设置在两个入口 | 单步弹窗 + 一个「编辑数据」 | **高** |
| 保密字典 | 类型只读 + 键值对 | 类型可改 + 类型化表单 | **高** |
| 持久卷声明 | 列含访问模式/挂载状态 | 列：名称/命名空间/状态/容量/存储类/创建时间 | 中 |
| 项目（namespace） | 显式选择 + 校验 | 下拉默认 default | 已做（够用） |

## 五、建议分批（每批独立可验收）

1. **P-A 配置字典 / 保密字典对齐**（1d）：两步创建 + 编辑信息/编辑设置拆分 + 密钥类型只读 + 列（字段/类型/字段数量）
2. **P-B 服务 / 路由 / 服务账户**（1d）：行操作拆分（编辑服务 / 编辑外部访问 / 编辑路由规则 / 编辑注解 / 修改角色）+ 列对齐（内部访问/外部访问/网关地址/角色）
3. **P-C 存储**（0.5~1d）：PVC 列补访问模式 / 挂载状态；存储类列补克隆/快照/扩展/供应者
4. **P-D 工作负载**（0.5d）：行操作命名对齐（编辑信息 / 重新创建），保留我们已有的伸缩/重启（KubeSphere 藏在详情页）
