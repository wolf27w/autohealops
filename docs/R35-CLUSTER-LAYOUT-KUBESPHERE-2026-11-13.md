# R35 集群内布局与资源页对齐 KubeSphere（2026-11-13 老板定）

> 老板口径：**进入集群之后的布局尽量和 KubeSphere 一样；只保留我要求过的那几块（应用负载 / 配置 / 存储 + 节点），其它可以不要；功能不砍，入口对齐，我们多的追加在后，删除置底。**
> 依据：2026-11-13 实地登录 KubeSphere 3.4.1（qa-eft 集群）抓取的 DOM + 老板提供的 7 张截图（OCR 逐字提取）。

## 一、集群内导航（目标）

```
概览                        /clusters/:id
节点                        /clusters/:id/nodes
应用负载
 ├─ 工作负载                  /clusters/:id/workloads/:kind   ← 页内 Tab 切换 部署/有状态/守护/定时
 ├─ 容器组                    /clusters/:id/pods
 ├─ 服务                      /clusters/:id/services
 └─ 应用路由                  /clusters/:id/ingresses        ← 新增独立页（现在混在「服务」页的第二个 Tab）
配置
 ├─ 配置字典                  /clusters/:id/configmaps
 └─ 保密字典                  /clusters/:id/secrets
存储
 ├─ 持久卷声明                /clusters/:id/storage
 └─ 存储类                    /clusters/:id/storageclasses
巡检与诊断                    /clusters/:id/inspection        ← 我们独有，保留
```

**明确不要（老板定）**：项目、定制资源定义、监控告警（已下线）、集群设置（基本信息/可见性/成员/角色/网关）、任务（k8s Job）、服务账户、卷快照、卷快照类。

**保留说明**：节点（老板点名保留）。

## 二、逐页对齐范围

### 节点
| 项 | KubeSphere | 我们 | 动作 |
|---|---|---|---|
| 列 | 名称 / 状态 / 角色 / CPU / 内存 / Pod 数 / IP / 创建时间 | 已有 + Kubelet | 保持（我们更全） |
| 行操作 | 编辑信息 / 编辑 YAML / 编辑污点 … | 节点诊断 / 标签污点 / 隔离 / 封锁 / 驱逐 | 保持 |

### 工作负载
| 项 | KubeSphere | 我们 | 动作 |
|---|---|---|---|
| 组织 | 一个页面，页内切换 部署/有状态/守护/定时 | 路由 `/workloads/:kind` + 左栏底部下拉 | 改页内 Tab，路由保留兼容 |
| 列 | 名称 / 状态 / 项目 / 更新时间 | 名称 / 状态 / 副本 / 更新时间 等 | 补「项目」列（命名空间） |
| 行操作 | 编辑信息 / 编辑 YAML / 重新创建 / 删除 | 编辑设置 / 编辑 YAML / 伸缩副本 / 滚动重启 / 发布历史 / 删除 | 入口对齐 → `编辑信息 / 编辑 YAML / 重新创建 / 编辑设置 / 伸缩副本 / 滚动重启 / 发布历史 / 删除` |

### 容器组
| 项 | KubeSphere | 我们 | 动作 |
|---|---|---|---|
| 列 | 名称 / 状态 / 节点 / 容器组 IP / 更新时间 | 已符合 | 补「容器组 IP」列（若无） |
| 行操作 | 查看 YAML / 删除 | 监控 / 日志 / 进容器 / JVM / 编辑 YAML / 隔离 / 删除 | 顺序对齐：`查看 YAML / 监控 / 日志 / 进容器 / JVM 诊断 / 隔离 / 删除` |

### 服务
| 项 | KubeSphere | 我们 | 动作 |
|---|---|---|---|
| 列 | 名称 / 项目 / 内部访问 / 外部访问 / 创建时间 | 名称 / 命名空间 / 类型 / ClusterIP / 端口 … | 补「内部访问 / 外部访问」两列 |
| 行操作 | 编辑信息 / 编辑 YAML / 编辑服务 / 编辑外部访问 / 删除 | 编辑设置 / 编辑 YAML / 删除 | 拆「编辑服务」与「编辑外部访问」两个入口 |

### 应用路由（新独立页）
| 项 | KubeSphere | 动作 |
|---|---|---|
| 列 | 名称 / 网关地址 / 项目 / 创建时间 | 从「服务」页拆出独立页面 |
| 行操作 | 编辑信息 / 编辑 YAML / 编辑路由规则 / 编辑注解 / 删除 | 拆两个入口 |

### 配置字典 / 保密字典
见 `docs/PA-CONFIGMAP-SECRET-SPEC-2026-11-13.md`（已开发中，P-A）：
- 创建：两步向导（基本信息 → 数据设置）+ 右上「编辑 YAML」
- 行操作：`编辑信息 / 编辑 YAML / 编辑设置 / 查看信息 / 删除`
- 列：配置字典「字段」；保密字典「类型 / 字段数量」

### 持久卷声明 / 存储类
| 页 | KubeSphere 列 | 我们 | 动作 |
|---|---|---|---|
| 持久卷声明 | 名称 / 状态 / 持久卷 / 访问模式 / 挂载状态 / 创建时间 | 名称 / 命名空间 / 状态 / 容量 / 存储类 / 创建时间 | 补「访问模式 / 挂载状态」 |
| 存储类 | 名称 / PVC 数 / 默认存储类 / 允许克隆·快照·扩展 / 供应者 | 名称 / 供应者 / 默认 | 补其余列 |

## 三、分批

| 批次 | 内容 | 状态 |
|---|---|---|
| **P-A** | 配置字典 / 保密字典（两步创建 + 编辑信息/编辑设置拆分 + 列名） | 开发中 |

| **P-D** | 工作负载：页内 Tab 切类型、补齐行操作（编辑信息/重新创建）、补「项目」列 | 待做 |
| **P-E** | 导航收口：左栏按第一节重排；老 URL 全部加重定向（`/services` 里的路由 Tab → `/ingresses`） | 待做 |

## 四、不改的东西（避免误伤）

- 我们的独有能力全部保留：监控/日志/进容器/JVM/隔离/伸缩/重启/发布历史/巡检与诊断/资源治理。
- 平台侧菜单（资源中心 / 告警监控 / 诊断与自愈 / 平台）不动。
- 后端接口不动（列和弹窗都用现有 API）。

## 五、验收口径

1. 进集群后左栏结构 = 第一节的树（不多不少）。
2. 每个列表页的**列名**与 KubeSphere 一致（我们额外列可保留在后面）。
3. 每个列表页的**行操作**：先 KubeSphere 那几项（顺序一致），再追加我们的，删除永远最后。
4. `npx tsc -b` 0 错、`npm run build` 通过；旧 URL 全部重定向到新页面。
