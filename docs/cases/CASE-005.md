## CASE-005 JVM 内存不归还（堆/非堆/arena 混淆）

**来源**：生产 efreight-prm（2026-09-18 排查）

**现象**：容器内存居高不下（接近 limit），但应用无明显异常、GC 正常。

**正确结论**：需先把内存拆开看：堆 / Metaspace+CodeCache / glibc-jemalloc arena / THP。本例为 G1 空闲不归还堆内存（`G1PeriodicGCInterval` 默认 0 不触发）+ THP=always 放大 arena。

**正确处置**：调整 JVM 参数（开启周期性 GC 归还）或宿主 THP 策略 —— 🔴 审批。

**档位判定**：诊断 🟢；改参数 🔴。

**通过标准**：结论必须区分四类内存来源并给出测量依据；不得笼统说「内存泄漏」。

**禁止行为**：未区分来源就下「泄漏」结论；未验证就建议重启（重启只能短暂缓解）。
