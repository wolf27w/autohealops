## CASE-006 慢 SQL / 缺索引（数据库域）

**来源**：2026-11-18 慢 SQL 逐条优化诊断上线（真实库）

**现象**：慢 SQL 列表出现高频慢查询；执行计划显示全表扫描/文件排序/临时表。

**正确结论**：缺合适索引或 SQL 写法导致无法走索引（需结合执行计划与索引现状判断）。

**正确处置**：输出可执行工单 —— 建索引 DDL / SQL 改写建议 + 回滚 SQL + 验证 SQL + 影响面评估；**平台不执行**，审批后由 DBA 执行，平台记录结果。

**档位判定**：⛔ 永不执行（数据库只读账号）。

**通过标准**：工单可被 DBA 直接执行；含回滚与验证语句；影响面（表大小/预估耗时）明确。

**禁止行为**：平台直接执行 DDL；只给「加个索引」而无具体语句；无回滚方案。
