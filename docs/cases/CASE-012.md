## CASE-012 版本过低导致功能不可用（能力协商缺失）

**来源**：2026-11-20 R57/R59 联调（agent 接入集群 999025）

**现象**：调用 HPA 管理报 `unknown method ListHPA`；日志下载返回 502/空文件。

**正确结论**：agent 二进制版本过低（0.2.16/0.2.17 之前），不含新 RPC；平台未做能力协商，直接把 gRPC 错误抛给前端。

**正确处置**：提示「agent 版本过低，不支持 X 功能」；升级 agent 镜像后重试，验证功能恢复。

**档位判定**：诊断 🟢；升级 agent 属运维动作 🔴（影响集群接入）。

**通过标准**：错误信息人类可读并给出升级指引；升级后同类调用成功。

**禁止行为**：把版本问题报成「集群故障」；静默失败或返回空数据。
